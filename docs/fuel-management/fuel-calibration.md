# Fuel Calibration (Web Only)

Configure fuel tank sensors for accurate fuel level readings.

## How to Calibrate

1. Navigate to **Fuel** from the sidebar
2. Select the **tank type**: Cube, Cylindrical, or Irregular
3. Enter **sensor voltage-to-liter mapping** values at various fill levels
4. The system generates a **calibration curve** for accurate fuel calculations
5. Save the calibration to the device

:::tip
For best accuracy, calibrate at multiple fill levels (empty, quarter, half, three-quarter, full).
:::
