# Video Surveillance

For vehicles equipped with cameras, Traqcare provides live and recorded video access.

| Feature | Description |
|---------|-------------|
| **Live Video** | Stream real-time video from vehicle cameras |
| **Video Playback** | Review recorded footage with timeline controls |
| **Device Images** | View snapshots captured by the device camera |
| **Multi-Camera** | View multiple camera feeds simultaneously |
| **Timeline** | Navigate to specific timestamps in recordings |
