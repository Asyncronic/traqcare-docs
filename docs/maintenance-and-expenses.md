# Maintenance & Expenses

## Maintenance Schedules (Web)

1. Navigate to **Maintenance > Schedules**
2. Click **Add Schedule**
3. Select the vehicle and maintenance type (Oil Change, Tire Rotation, Service, etc.)
4. Set the trigger: by date, by mileage, or both
5. Set recurrence (one-time or repeating)
6. The system alerts you when maintenance is due

## Expense Tracking

1. Navigate to **Expenses**
2. Click/tap **Add Expense**
3. Select vehicle, category (Fuel, Service, Insurance, etc.), amount, date
4. Optionally attach a receipt photo
5. Save

View expense history with filtering by vehicle, category, or date range.
