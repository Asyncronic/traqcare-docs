# Alert Types

| Alert Type | Triggers When | Example Use |
|------------|---------------|-------------|
| **Overspeed** | Vehicle exceeds a set speed limit | Fleet safety compliance |
| **Geofence Entry** | Vehicle enters a defined zone | Customer site arrival notification |
| **Geofence Exit** | Vehicle leaves a defined zone | Unauthorized departure detection |
| **Device Offline** | Device stops sending data | Hardware malfunction or tampering |
| **Ignition On/Off** | Engine started or turned off | After-hours usage monitoring |
| **Harsh Braking** | Sudden deceleration detected | Driver safety monitoring |
| **Harsh Acceleration** | Sudden acceleration detected | Driving behavior analysis |
| **Low Battery** | Device battery drops below threshold | Portable tracker maintenance |
| **Fuel Theft** | Sudden fuel level drop detected | Fuel security |
| **Maintenance Due** | Scheduled maintenance date/mileage reached | Preventive maintenance |
