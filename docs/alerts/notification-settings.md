# Notification Settings

Configure how you receive alert notifications.

## Mobile Settings

| Setting | Description |
|---------|-------------|
| **Push Notifications** | Toggle real-time push alerts on/off |
| **Voice Alerts** | Audible spoken alerts when notifications arrive |
| **Notification Sound** | Custom alert sound selection |

Access via **More > Settings** on the mobile app.

## Web Settings

Desktop notifications and email alerts can be configured per alert subscription when creating or editing alerts.
