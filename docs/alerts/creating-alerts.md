# Creating Alerts

1. Navigate to **Alerts** (Web: sidebar, Mobile: More > Alerts)
2. Click/tap **Add New Alert**
3. Select the **alert type** (e.g., Overspeed)
4. Choose the **vehicles/objects** to monitor
5. Set the **threshold** (e.g., speed limit of 120 kph)
6. Choose **notification method**: in-app, push notification, email, or SMS
7. **Save** the alert

:::tip
You can create multiple alerts for the same vehicle with different thresholds — e.g., a warning at 100 kph and a critical alert at 120 kph.
:::
