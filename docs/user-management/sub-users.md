# Sub-Users

Create additional user accounts with controlled access to your fleet.

## Creating a Sub-User

1. Go to **Settings > Sub-Users**
2. Click **Add User**
3. Enter name, email, username, password
4. Assign a role (User or Admin)
5. **Link specific vehicles** — choose which vehicles this user can see
6. Save

:::tip
Sub-users can only see the vehicles you link to them. This is useful for giving drivers access to only their own vehicle.
:::
