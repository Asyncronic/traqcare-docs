# Geofences

Geofences are virtual boundaries on the map. Get notified when vehicles enter or leave these zones.

## Creating a Geofence

1. Navigate to **Geofences** (Web: GeoJsons > Geofence, Mobile: More > Geofence)
2. Click/tap **Add New Geofence**
3. Choose the shape:
   - **Circle** — Set a center point and radius
   - **Polygon** — Draw a custom shape by placing points on the map
4. **Name** the geofence (e.g., "Office", "Warehouse", "Customer Site")
5. **Save**

## Managing Geofences

- View all geofences on the list or map
- Edit name, shape, or size
- Delete geofences no longer needed
- Link geofences to alerts for entry/exit notifications

## Geofence Dashboard (Web Only)

A dedicated analytics dashboard showing:
- Entry/exit event counts per geofence
- Visit frequency charts
- Dwell time analysis (how long vehicles spend inside each zone)
- Map visualization with geofence data overlay
