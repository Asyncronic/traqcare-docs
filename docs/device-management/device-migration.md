# Device Migration (Mobile)

:::tip Video Tutorial
<video controls width="100%">
  <source src="/videos/how-to-migrate-object.mp4" type="video/mp4" />
</video>
:::

Transfer a GPS device from one vehicle to another:

1. Go to **Device Migration**
2. Select the **source vehicle** (where the device currently is)
3. Select the **target vehicle** (where to move it)
4. Confirm the migration

The device history remains with the original vehicle record.
