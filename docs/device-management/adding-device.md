# Adding a Device

## Steps

1. **Web:** Go to Settings > Devices > Add Device | **Mobile:** Go to More > Device Form
2. Enter the device **IMEI number** (printed on the device or box)
3. Select the **device type/model**
4. Enter a **name** for the vehicle/asset being tracked
5. Optionally enter SIM card details
6. Assign to a user (if applicable)
7. Save and activate

:::tip
On mobile, use the **QR Code Scanner** to quickly scan the device's IMEI barcode instead of typing it manually.
:::
