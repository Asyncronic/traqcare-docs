# Mobile Reports

The Traqcare app has eight reports for a single vehicle: daily travel, daily distance, stops, trips, alerts, fuel, speed and idling. You open them from the vehicle, choose a period, read the results on the phone and, if needed, save them as a PDF.

![Mobile Reports](/img/screenshots/mobile/reports.jpg)

## Open a report

1. Open the **List** tab and tap the vehicle.
2. Tap **Reports**. You can also tap **Reports** in the action row of the vehicle's live map.
3. Tap a report tile. It loads straight away for its default period.

Reports are not in the More tab, because each report belongs to one vehicle.

## Choose the period

1. Tap the calendar icon in the report's top bar.
2. Set the **From** date and time and the **To** date and time, or tap the filter icon and pick **Today**, **Yesterday**, **This Week**, **Last Week**, **This Month** or **Last Month**.
3. Tap the send icon to load the report.

Daily Travel Summary, Daily Distance, Alerts, Fuel Summary and Speed vs Distance open with the last 7 days (today and the six days before). Stoppage Summary, Trips Summary and Idle Report open with today.

## Save as PDF

Tap the download icon in the report. When the file is ready you see "Report saved at" followed by the file location, with an **Open** button. If the report is empty you see "No data to download" instead. PDF column headings are in English whatever the app language.

## The eight reports

1. **Daily Travel Summary**: one row per day with start and end time and address, run time, idle time, stop time, distance, max speed and number of trips.
   ![Daily Travel Summary](/img/screenshots/mobile/daily-travel-summary.jpg)
2. **Daily Distance**: the distance driven in each day of the period.
   ![Daily Distance](/img/screenshots/mobile/daily-distance.jpg)
3. **Stoppage Summary**: every stop with start time, end time, address and stop duration.
   ![Stoppage Summary](/img/screenshots/mobile/stoppage-summary.jpg)
4. **Trips Summary**: every trip with start and end time, start and end address, max speed, trip duration and trip distance.
   ![Trips Summary](/img/screenshots/mobile/trips-summary.jpg)
5. **Alerts**: each alert with date, alert name, address, latitude and longitude. Use this report for alerts older than the 24 hours shown in the alerts list.
   ![Alerts](/img/screenshots/mobile/alerts-1.jpg)
6. **Fuel Summary**: one row per day with fuel consumed (litres), **Theft** and **Refuel** events, distance and max speed. Tap a day to open its fuel chart, which turns to landscape.
   ![Fuel Summary](/img/screenshots/mobile/fuel-summary.jpg)
7. **Speed vs Distance**: **Total Distance**, **Total Time** and **Avg Speed**, with a **Speed Range Breakdown** of the driving in each speed band. Tap to view the chart in landscape.
   ![Speed vs Distance](/img/screenshots/mobile/speed-vs-distance-reports.jpg)
8. **Idle Report**: each idle period with start time, end time, address and idle duration.
   ![Idle Report](/img/screenshots/mobile/idel-report.jpg)

Distances and speeds use the unit set in **More > Preferences > Distance Unit**.

## Common questions

### Where are the Travel Summary and other web reports?

The app has the eight reports above. Other reports, such as geofence and custom reports, are on the web platform. See [Reports](../reports.md).

### Why does a report say "No Data available for selected time period"?

The vehicle has no records of that kind in the chosen period. Pick a longer or different period and tap the send icon again.

### Where is the PDF saved?

On Android it goes to the app's own storage folder on the phone; on iPhone, to the app's own files. Use **Open** in the message to view it straight away.
