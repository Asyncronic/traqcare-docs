# Mobile Reports

Access via **More > Reports**. Select a vehicle and date range.

## Available Reports

1. **Daily Travel Summary** — Daily movement summary
2. **Daily Distance** — Distance per day
3. **Stoppage Summary** — All stops with location and duration
4. **Trip Summary** — Individual trips with distance and speed
5. **Alert Report** — Triggered alert history
6. **Fuel Summary** — Fuel consumption with interactive chart
7. **Speed & Distance** — Speed statistics
8. **Idle Report** — Engine idle events
9. **Travel Summary** — Aggregated travel metrics
