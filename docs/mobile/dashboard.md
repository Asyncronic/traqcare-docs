# Mobile Dashboard

The dashboard provides an at-a-glance overview of your fleet.

![Mobile Dashboard](/img/screenshots/mobile/dashboard.jpg)

- **Status Pie Chart** — Visual breakdown of vehicle states (Online, Offline, Idle, Moving, Parked)
- **Object Count** — Total tracked vehicles with status breakdown
- **Quick Filters** — Tap any status to filter the list
- **Dashboard Map** — Mini map showing all vehicle locations
- **Client Selector** — Switch between clients (for resellers)
