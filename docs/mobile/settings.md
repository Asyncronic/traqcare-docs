# Mobile Settings

Access from the **More** tab.

![Mobile More Menu](/img/screenshots/mobile/more.jpg)

| Setting | Description |
|---------|-------------|
| **Notifications** | Toggle push notifications on/off |
| **Voice Alerts** | Enable spoken alert notifications |
| **Include Sub-Clients** | Show sub-client vehicles (Reseller) |
| **Alert Configuration** | Configure alert thresholds |
| **Home Screen** | Default screen: Dashboard, List, or Map |
| **Language** | 13+ languages available |
| **Distance Unit** | Kilometers or Miles |
| **Change Password** | Update your password |
| **Terms of Use** | View terms |
| **Privacy Policy** | View privacy policy |
| **Logout** | Sign out of the app |
