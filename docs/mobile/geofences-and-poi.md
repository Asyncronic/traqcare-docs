# Geofences & POI (Mobile)

## Geofences

Access from **More > Geofence**:
- View existing geofences on the map
- Create new geofences (circle or polygon)
- Edit or delete geofences
- Configure entry/exit alerts

## Points of Interest

Access from **More > POI**:
- Create custom POI markers on the map
- Edit or remove POI points
- Toggle POI visibility on tracking maps
