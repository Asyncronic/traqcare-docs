## Creating a POI

1. Navigate to **POI** (Web: GeoJsons > POI, Mobile: More > POI)
2. Click/tap **Add New POI**
3. Place the marker on the map or enter coordinates
4. Name the POI (e.g., "Fuel Station", "Client Office")
5. Save

POI markers can be toggled on/off on the live tracking map for reference.
